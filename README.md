# FracLap

**A Lean 4 + Mathlib formalization of the fractional Laplacian**, with a 1-to-1 human-readable
**`leanblueprint`**, an anti-vacuity test suite, and multi-kernel verification.

**Documentation site**: <https://bwrob.github.io/frac-lap-lean/> (blueprint and Lean side by side).

## What is formalized

The library covers the theory of the fractional Laplacian $(-\Delta)^{\alpha/2}$, $0<\alpha<2$:

- **Whole line**: the stable heat kernel (positivity, monotonicity, algebraic tail decay, unit mass), the
  fractional heat semigroup as an $L^2$ Fourier multiplier and as convolution, the Gagliardo energy and its
  exact Fourier symbol, Sobolev equivalence, and the pointwise singular-integral and heat-subordination
  identities. The whole-line semigroup extends holomorphically to the right half-plane.
- **Half line**: the reflected (spectral) semigroup, the restricted exterior-Dirichlet form and its semigroup, energy ordering, smoothing, and
  Constantin–Vicol type maximum principles.
- **Semigroup core**: $C_0$ contraction semigroups, contractive resolvents and the Hille–Yosida
  correspondence, written for the needs of the above.
- **Tools**: the Stroock–Varopoulos inequality, the fractional Nash inequality and the resulting decay,
  Bernstein inequalities, Young's inequality, the Hardy–Littlewood maximal function and Stein's maximal
  inequality, Poincaré inequalities, the beta integral.

The starting point is the author's 2016 master's thesis, *Anomalous Diffusion Equation on the Half-Line*.
A statement is *formalized* only if Lean accepts it, and a proof counts only if it contains no `sorry`.

## Layout

- `FracLap/` and `FracLap.lean`: the library (`autoImplicit = false`, `mathlibStandardSet`, `warningAsError`).
- `FracLapTest/` and `FracLapTest.lean`: anti-vacuity witnesses and negative counterexamples.
- `blueprint/src/`: the 1-to-1 LaTeX blueprint (`content.tex` is a pure `\input` aggregator).
- `scripts/`, `comparator.json`: axiom audit, structural audit, import and parity checks, documentation generator.
- `docs/`, `zensical.toml`: documentation site; `docs/knowledge/` is generated by `scripts/gen_docs.py`.
- `.github/workflows/`: CI (build, lint, audits, blueprint declarations), documentation deployment, weekly kernel replay.

## Working with the repository

```bash
just cache          # fetch the precompiled Mathlib cache (never compile Mathlib locally)
just build          # lake build
just test-lean      # build the anti-vacuity tests
just check          # pre-commit hooks (prek)
just check-push     # pre-push tier: build, tests, imports, axioms, gap audit
just verify-all     # full verification, run at milestones
just docs-serve     # preview the documentation site
just new-module Tools/Foo   # scaffold a module with its blueprint chapter and test
```

The library depends on Lean 4 and Mathlib only. See `AGENTS.md` for the contribution rules.
